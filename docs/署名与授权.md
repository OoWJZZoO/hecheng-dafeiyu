# 署名与授权（游戏署名页唯一源）

> 这是游戏「关于与署名」措辞的唯一来源。改这里，然后在仓库根目录运行 `python tools/build.py`。
> 构建会重新生成 `text.json` 的「署名页」。
>
> 生成物不要手改，下次构建会被覆盖。署名是授权要求，改措辞前先和作者确认。
>
> 只想同步署名文案、不跑整个游戏构建：`python tools/attribution.py --write`；
> 只检查生成物有没有落后：`python tools/attribution.py --check`。
>
> 格式约定：`##` 是文案组，`###` 是字段；标题类字段只写一行；段落每行一段，
> 行首的 `- ` 会被去掉。段落里的 `**粗体**`、`[文字](网址)` 会原样进游戏署名页（链接是可点的 `<a>`）。
